## 🚀 Головний проєкт: [samaevv-assistant](https://github.com/samaevv/samaevv-assistant) · «Джарвіс»

Український голосовий асистент для Linux. Слухає слово активації, розуміє вільні фрази, відкриває програми й керує вікнами, шукає музику й відео, веде нотатки, дає поради. Власні команди створюються **з опису словами**.

| | |
|---|---|
| 🎙️ **Слух** | розпізнавання мови на твоєму ПК (Whisper), без хмари |
| 🧠 **Мозок** | безкоштовна локальна модель (Ollama + Gemma) або Claude / Codex |
| 🧩 **Плагіни** | 30+ вмінь: погода, Obsidian, радіо, нагадування, OCR, жести камерою |
| 🖥️ **Центр керування** | у браузері, на будь-якій системі, скляний інтерфейс |
| 🔒 **Приватність** | усе локально, твої дані ніколи не залишають комп'ютер |

**Встановлення однією командою** (Arch / Omarchy, Ubuntu / Debian, Fedora, openSUSE):

```bash
curl -fsSL https://raw.githubusercontent.com/samaevv/samaevv-assistant/main/get.sh | bash
```

> Стадія: бета. Найкраще перевірено на Omarchy (Arch + Hyprland); інші системи підтримані, але чекають на тестувальників. Знайшов помилку? Відкрий issue!
